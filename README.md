# 📐 DeltaCode

**Matemática + Programación** Un espacio para redescubrir el pensamiento lógico a través del código.

## 🚀 Sobre el Proyecto

DeltaCode es una plataforma educativa diseñada para integrar el aprendizaje de las matemáticas con el desarrollo de software. Este sitio sirve como hub para lecciones interactivas, proyectos en Python y recursos didácticos modernos.

## 🛠️ Mi Stack Tecnológico

- **Frontend:** Astro (v6) + Tailwind CSS
- **Lógica & Datos:** Python + Google Colab
- **IA & Copiloto:** Gemini 3 Flash
- **Infraestructura:** GitHub + MDX

## 📂 Estructura

- `/src/content/blog`: Artículos y tutoriales matemáticos.
- `/src/content/tech`: Herramientas del stack.
- `/src/pages`: Estructura principal del sitio.

## El desafío

¿Cómo podemos enseñar algoritmos sin empezar por definiciones abstractas?

Este proyecto parte de un juego simple: adivinar un número secreto entre 0 y 100. A partir de esa experiencia, los estudiantes comparan estrategias, analizan sus intentos y descubren que elegir siempre el punto medio permite reducir rápidamente el espacio de búsqueda.

La programación aparece como una herramienta para pensar matemática, no como un tema aislado.

## Qué construimos

Desarrollamos una actividad en Python basada en el juego “Adivina el número”, diseñada como laboratorio matemático para el aula. El proyecto permite explorar cómo una estrategia ordenada puede ser mucho más eficiente que el azar.

Incluye:

- **Juego interactivo en Python**: los estudiantes prueban estrategias para encontrar el número secreto.
- **Método de bisección**: se introduce la idea de dividir el intervalo en dos partes y elegir el punto medio.
- **Análisis de eficiencia**: se estudia por qué bastan como máximo 7 intentos para encontrar cualquier número entre 0 y 100.
- **Valor absoluto**: se usa la distancia al número secreto para generar pistas y analizar errores.
- **Guía docente**: orientaciones para implementar la actividad en clase y abrir discusiones matemáticas.

## Decisiones de diseño

**Del juego al algoritmo**  
La actividad comienza con una experiencia intuitiva y luego formaliza la estrategia matemática detrás del juego.

**Python como laboratorio**  
El código está pensado para ser simple, modificable y accesible, incluso para docentes que no son programadores.

**Error como parte del aprendizaje**  
Los intentos fallidos permiten analizar estrategias, comparar resultados y mejorar el algoritmo.

## Para qué sirve en el aula

Este proyecto ayuda a trabajar:

- pensamiento computacional,
- intervalos y punto medio,
- búsqueda binaria,
- eficiencia algorítmica,
- valor absoluto,
- razonamiento lógico,
- y modelización matemática con Python.

Es una propuesta pensada para docentes de Matemática de nivel secundario que quieran introducir programación de manera gradual, visual y significativa.

## El Problema

Buscaba una forma de enseñar algoritmos que no pareciera aburrida o puramente teórica para mis alumnos. El objetivo era simple: pasar de una fórmula en la pizarra a un código en Python que 'piensa'. Muchas veces, la programación se enseña de forma aislada, pero en DeltaCode buscamos que sea el puente para entender conceptos matemáticos profundos de forma interactiva.

## Qué Construí

Desarrollé una implementación del [Método de Bisección](https://colab.research.google.com/drive/1TEm8GpFwZOfdHgsi9HukEJd1zn2dJ6Cq?usp=sharing) en Python, diseñada como un laboratorio matemático para el aula. El proyecto permite a los estudiantes visualizar cómo la lógica binaria reduce drásticamente el azar. He incluido:

- **Algoritmo de Bisección**: Un script de Python que resuelve el juego 'Adivina el número' con eficiencia logarítmica.
- **Análisis de Eficiencia**: Comparativas que muestran por qué con solo 7 intentos podemos adivinar cualquier número entre 1 y 100.
- **Integración de Valor Absoluto**: Uso de funciones matemáticas para calcular la 'distancia' al objetivo y dar pistas dinámicas.
- **Guía Didáctica**: Material de apoyo para que otros docentes puedan replicar la experiencia en sus clases.

## Decisiones de Diseño

**Enfoque STEM** : Integré Ciencia, Tecnología, Ingeniería y Matemáticas en un solo ejercicio práctico, siguiendo los estándares educativos europeos.

**Python como Laboratorio** : Decidí usar un lenguaje accesible para que el foco esté en la lógica y no en la sintaxis compleja.

**Visualización de Errores** : El código está diseñado para fallar de forma 'educativa', permitiendo que el alumno vea por qué una estimación es mejor que otra mediante el método científico.

## Resultados

- **Impacto en el Aula**: Estudiantes que comprenden el crecimiento logarítmico sin necesidad de memorizar tablas complejas.
- **Código Abierto**: Todo el repositorio de DeltaCode está disponible en **GitHub** y **Google Colab** bajo licencia MIT para uso educativo.
- **Metodología Probada**: Un recurso listo para ser implementado en cualquier clase de matemáticas de nivel secundario.
